## Technical decisions

### Spring AI starter over low-level MCP SDK

**Decision:** Use Spring AI MCP starters for the application server.

**Reasoning:** The repository is a Spring Boot application and the Spring AI abstraction keeps the initial implementation small while still exposing MCP tools cleanly.

**Alternatives considered:** A lower-level MCP Java SDK server was discussed as reference material, but it was not the default implementation route for this repository.

### Streamable HTTP for the server transport

**Decision:** Configure the MCP server for Streamable HTTP with a servlet-based WebMVC starter.

**Reasoning:** That matches the existing Spring Boot application shape and gives a straightforward local endpoint for Codex CLI and the MCP Inspector.

**Alternatives considered:** STDIO or SSE were not used for the current prototype.
